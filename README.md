# ポートフォリオまとめ
これまでに作成したWebアプリや作品のまとめです。

## 🛠 作品一覧

### 🦠 CoronnaTracker
- **概要**: 外部APIと連携し、国別の累計・日別感染者数を可視化するトラッキングアプリ。
- **学習の目的**: ReactとTypeScriptによる型安全な非同期データ取得・動的UI構築の習得。
- **リポジトリ**: [CoronnaTracker](https://github.com/Agiat-png/CoronnaTracker)

### 🧮 Dentaku (高機能レトロ電卓)
- **概要**: 00年代コンピュータ風のUIを備えた、独自の入力制御（括弧・ドット補完）を実装したWeb電卓。
- **学習の目的**: JavaScriptによる複雑なDOM操作、イベント処理、および堅牢な入力バリデーションの習得。
- **リポジトリ**: [Dentaku](https://github.com/Agiat-png/Dentaku)

### 📚 RubyPortfolioReviewMemo
- **概要**: 感想を書き溜めるためのRuby on Rails製Webアプリケーション。
- **学習の目的**: CRUD機能やログイン機能の実装、およびGitHub Actionsを用いたCI/CDの導入。
- **リポジトリ**: [RubyPortfolioReviewMemo](https://github.com/Agiat-png/RubyPortfolioReviewMemo)

### BentoWigetByReact /WigetSiteByTailwindCSS-app 

- **概要**: ウィジェットをカード形式で入れ替えられるSPA

- **学習の目的**: Reactを含むDOMを含むページの作成、APIの理解、TailwindCSSの理解
